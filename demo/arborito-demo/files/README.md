# Arborito demo

Esta rama te enseña Arborito paso a paso: mapa, lecciones, juegos, puntos y modo construcción.

La escribió **Sage** para que empieces sin manuales técnicos. Ábrela desde **Bosque → Ramas**.

Es una guía embebida de solo lectura (como un curso en línea de otro autor): puedes explorarla entera, incluso la construcción. Para editarla: modo construcción y un nombre para tu copia. Tras un reset completo de datos locales (`reseteverything`) vuelve a sembrarse sola.
